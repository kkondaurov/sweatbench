Two scores, kept separate

Core /39
Required product behavior, including business rules, persistence, retries and upgrades. Each family earns one point when all of its checks pass.
Maintenance /10
Five checks of old production data surviving later changes, and five checks of interactions among payments, credits, transfers and reporting. Automated pass counts, not reviewer ratings.
Sweep
A run with 39/39 Core and 10/10 Maintenance.
Ship / final /94
Scenario totals before and after subsequent milestone work. Final combines the last private tests with historical system checks at their designated milestones; it is not 94 fresh checks of the terminal code.
Recovery
Final minus ship-time scenarios. A later repair does not erase a migration failure recorded when its milestone shipped.

Completed runs, small samples

The Models view contains 67 completed, valid runs. Each configuration's sample size appears beside its name. Incomplete, abandoned, interrupted and evaluator-invalid attempts are excluded. Small samples are descriptive, not a reliable ranking or variance estimate; plotted ranges are observed minima and maxima, not confidence intervals.

These are comparisons of tested model-and-harness systems. Astra uses Codex CLI 0.153.4; earlier GPT runs used an older Codex version. The six completed Astra runs used ordinary v6 handoff prompts and launched no subagents. Opus 5 uses Claude Code 2.1.243 with customizations disabled. Muse Spark uses OpenCode 1.18.27; the controlled harness comparison uses OpenCode 1.18.0.

The Harnesses view reuses 20 standard Codex runs and adds 20 OpenCode runs plus five delegated-Luna runs. Its 45 runs overlap the Models view, so the two tab counts must not be added.

Astra's largest recorded request was 113,468 input tokens, below its 272K long-context threshold; cache-write counts were zero. GPT-5.5's recorded context window was 258,400 tokens. Other historical per-request surcharges and cache-write charges cannot be reconstructed consistently; those estimates use standard rates.

Codex reports cached input within total input; OpenCode reports uncached input and cache reads separately. The estimates normalize these schemas. Replaying accumulated context can dominate cost: cache reads account for roughly $12–14 per Kimi run and $13–22 per GLM 5.3 run.

Model-specific accounting

GLM-5.3 Flash ran as the free OX Alpha preview; displayed costs use its announced production rates. Opus's two subscription runs recorded $43.96 and $51.35 in API-equivalent usage. The OpenCode harness comparison used subscription OAuth with $0 incremental inference billing.

Muse Spark's $53.61 recorded charge includes two automatic continuations after turn-length limits. DeepSeek run 2 includes $0.32 for a redundant review that made no file edits.

Code, runtime & delegation

Code size is physical lines, including blanks and comments, in the final snapshot: production is lib/ plus migrations; tests are test/. The comparison shows medians. Fewer lines alone do not imply better code.

Runtime is the sum of seven agent-session wall-clock intervals, including reasoning, tools, tests and continuations. Private evaluation, snapshots and milestone advancement are excluded. DeepSeek run 4 excludes a documented 10h 52m machine interruption, retaining activity on either side.

Subagents counts unique children explicitly launched by the candidate, excluding fixed harness workers such as Codex auto-review. Those workers still count toward inference cost.
