What the scores mean

C /39
Core: does the product work? This covers the features and business rules requested across seven development milestones, including persistence, retries, upgrades, and previously completed behavior. A score of 37/39 means that 37 of 39 required areas passed. Upgrade steps are graded when their milestone ships, so an earlier migration failure can remain recorded even if later behavior recovers.
M /10
Maintenance: do upgrades and feature interactions stay correct? This is an automated pass count, not a reviewer rating. Five predefined checks cover old production data surviving later changes; five cover interactions among payments, credits, transfers, and reporting. A score of 7/10 means seven of those ten checks passed.

GPT-5.5's recorded Codex context window was 258,400 tokens. Other individual-request surcharges and historical cache-write charges cannot be reconstructed consistently, so these remain standard-rate estimates, not subscription invoices.

Astra low, medium, and high each have one completed run through Codex CLI 0.153.4 with unchanged v6 tasks and ordinary handoff prompts. None launched subagents. Earlier GPT runs used an older Codex version: this compares the tested model-and-harness systems, not an isolated change of model weights. Astra pricing was checked on 5 September 2026.

GLM-5.3-Flash was first tested under its anonymous preview name, OX Alpha. The preview charged $0; all four displayed samples use API-equivalent estimates at the announced production rates of $0.15 input, $0.50 output, and $0.03 cached input per million tokens, with reasoning tokens billed as generated output.

Kimi K3 and GLM 5.3 (not Flash) repeatedly process long accumulated contexts. Cache-read charges account for roughly $12–14 of each Kimi run and $13–22 of each GLM 5.3 run, which is the main reason their totals are higher than the headline token prices might suggest.

Those cache reads are the discounted cost of replaying the growing agent conversation on later tool turns, not duplicated evaluator traffic. Private evaluation is excluded. A different harness could manage context more efficiently, so this is a practical configuration cost rather than a claim about the model's intrinsic cost.

LOC is measured on each final milestone snapshot and displayed as the median across accepted runs. Production includes lib/ and database migrations; Test includes test/. These are physical lines, including comments and blanks.

Opus 5 used Claude Code 2.1.243 with customizations disabled, the same frozen benchmark and handoff protocol, endogenous tests, public network access, and an isolated candidate workspace. Claude Code recorded $43.96 and $51.35 of API-equivalent usage across the two seven-milestone runs; the subscription itself was not billed per token.

Core and Maintenance remain separate by design. A sweep means 39/39 Core and 10/10 Maintenance in the final state. Recovery is the increase from ship-time scenarios to final-state scenarios out of 94.

Runtime is the sum of candidate agent-session wall-clock intervals across seven milestones. Private evaluation, snapshotting, and request-advance time are excluded. It measures the observed speed of the tested model + harness/provider configuration, rather than raw token throughput.

Subagents counts unique child agent sessions explicitly launched by the candidate during an accepted run. Fixed harness-owned workers such as Codex auto-review are excluded.

OpenCode totals include continuation calls and descendant task sessions required to finish each accepted run. Abandoned, incomplete, evaluator-invalid, and infrastructure-debug runs are excluded entirely. The audited totals are preserved in accepted-runs.json and checked by analyze.py.

DeepSeek Run 2 includes $0.32 from a redundant same-session review caused by a retry-classifier false positive. The extra review made no file edits, so the scored artifact was unchanged; the displayed cost remains the spend actually incurred.

DeepSeek Run 4 runtime excludes a documented 10h 52m machine interruption inside its resumed first-milestone log. Model activity before and after the interruption is retained; the inactive wall-clock gap is not counted as agent runtime.

Its actual marginal billing was $0, but the displayed estimates answer the counterfactual question: what would the recorded inference have cost at API list prices?

Codex reports cached input as a subset of total input; OpenCode reports uncached input and cached reads separately. The calculation normalizes those schemas before applying Sol $4 / $0.40 cached / $20 output, Terra $2 / $0.20 / $12, and Luna $0.20 / $0.02 / $1.20 per million tokens.
