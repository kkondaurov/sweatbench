# C1: expired-credit revival

**Concept.** A late application revives only the applied portion of a published expiry.

**Entitlement.** Request 2 pauses expiry while credit funds an active group. Request 6 reports expiry
without an operation. Request 7 preserves the closed report while posting the later correction on the
first open day.

**Scenario.** Reuse the predeclared period-close scenario in which expired credit is applied with an
old event date after publication. The closed report stays stable; liability and the late expiry
reversal agree.

**Canary.** Treat the published expiry as irrevocable and leave revived liability at zero.
