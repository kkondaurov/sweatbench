# Judgment ladder

The Judgment track contains ten predeclared families whose outcomes are derivable from the
candidate-visible product history but are not supplied as executable examples. Core remains the
39-family regression floor. Judgment is reported separately and is never included in regression
episode accounting.

Each family document fixes four things before candidate runs begin: the engineering concept, the
candidate-visible entitlement chain, the evaluator scenario, and a narrow red-canary fault. The
family definition hashes in `benchmark.json` make later edits visible.

The candidate packet is unchanged. These documents, tests, and system checks are evaluator-only.
